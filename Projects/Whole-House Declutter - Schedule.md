# Declutter Schedule

Linked from [[Whole-House Declutter & Reorganization]]. Pace: **one short session (~45-60 min), every Wednesday at 8:00pm** — deliberately small so it doesn't become overwhelming. Dates below are targets, not deadlines; if a week gets skipped, just shift everything down rather than doubling up the next week.

> [!important] Re-anchored 2026-08-23
> The original schedule ran Saturdays from Aug 8 and **never started** — zero of 37 sessions in three weeks, while those same weeks produced heavy off-hours work elsewhere. A floating weekly task lost that contest every time. The fix isn't a later date, it's a fixed slot: sessions are now pinned to **Wednesday 8:00pm**, after BRC rounds and after meal prep. Week 1 restarts at Aug 26, 2026 and the whole table shifted with it — the run now ends **May 5, 2027** rather than Apr 17.

Each session = one line in the [[Whole-House Declutter - Room Checklist]]. Only the **current week's** session lives as an open task in Todoist (`prj-declutter`); the Monday weekly review promotes the next one and checks off the last, per the [[_Todoist Link Convention]].

37 sessions total, roughly **Aug 2026 → May 2027**. Sustain phase (seasonal re-pass) starts after that.

## How this stays current

- Each Monday review (per the weekly note routine): check off last week's session in the [[Whole-House Declutter - Room Checklist|Room Checklist]], mark the current week's Todoist task done if finished, and create/promote next week's task with the content from the row above — **dated to that week's Wednesday at 8:00pm**, not left dateless.
- If a session runs long or short, don't renumber the whole table — just note the actual date it happened in the [[Whole-House Declutter & Reorganization|project log]] and let subsequent weeks drift accordingly.
- Update `next_action` on the main project note to always name the upcoming session.
