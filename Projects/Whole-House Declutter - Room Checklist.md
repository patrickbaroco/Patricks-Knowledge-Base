# Whole-House Declutter — Room Checklist

Linked from [[Whole-House Declutter & Reorganization]]. Work rooms in order. Within each room, purge every zone (Keep / Donate-Sell / Trash-Recycle / Undecided) before starting that room's organize pass. Check off zones as they're done and update `last_touched` on the main project note when a whole room is complete.
